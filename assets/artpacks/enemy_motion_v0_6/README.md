# Enemy Motion Art Pack v0.6

本目录消费 `pxf77/MortalPath-Art` 的固定发布：

- 版本：`artpack-v0.6.0-enemy-motion-refinement`
- Release 目标提交：`1b68d0c68bf069c710265ce3ac1d8e21a27a4710`
- 美术实现提交：`d3b06745ac4a0292bd5f8c1b30938fd1360bb5f8`
- 运行时角色：近战炼气修士、远程符修、筑基守阵修士

## 运行时契约

- 三类角色共享 `humanoid_v1` 骨架；
- 待机和移动由敌人速度驱动；
- 攻击动作由既有 AI 的开始/释放时点驱动；
- 受击根据攻击者相对方向选择前、后、左、右轻重动作；
- 筑基守阵修士在减伤生效时使用护阵架势；
- 死亡后只恢复表现可见性以播放死亡动作，碰撞和 AI 仍保持关闭。

动画不拥有 AI、移动、伤害、碰撞、冷却、投射物或境界规则。
