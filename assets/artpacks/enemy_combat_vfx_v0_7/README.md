# Enemy Combat VFX Art Pack v0.7

本目录消费 `pxf77/MortalPath-Art` 的固定发布：

- 版本：`artpack-v0.7.0-enemy-combat-vfx`
- Release 目标提交：`ef32abf3d749fbd17d3bc70611881f5bd97ded0a`
- 美术实现提交：`46065843e69f52f5c3ba43bab0d692e5ff94a6ed`
- 运行时资产：3 套蓄力警示、2 套投射物、2 档命中特效

## 运行时契约

- 近战、符修与筑基守关者使用不同轮廓的蓄力警示；
- 警示显隐仍由敌方既有攻击前摇控制；
- 符箓与守关投射物只替换占位网格，不改变速度、碰撞、伤害或寿命；
- 普通敌人与守关者命中玩家时使用不同层级的瞬时效果；
- 脉冲、旋转、特效寿命、缩放与抬升参数从 Manifest 读取。

VFX 只负责表现；AI、攻击释放、命中结算、护体规则和投射物生命周期继续由游戏逻辑控制。
