# Art Guides

本目录保存 MortalPath 的轻量美术基线和可直接在仓库中预览的参考资产。

## 文件

- `art-direction-board-v0.1.svg`：初版整体方向参考板。
- `palette-v0.1.svg`：已锁定的基础色板。

## 使用规则

- 参考板用于构图、气质、色彩、角色轮廓和境界递进讨论；
- 参考板中的生成文字、数值、界面和具体人物不是正式设定；
- 正式规范以 `docs/art-direction/` 中的文字为准；
- 后续 Style Frame 应使用无字原画或人工排版文字；
- 不直接从参考板裁切角色、图标、法器或 UI 作为游戏资产。
