# 境界视觉层级规范

## 1. 目的

本规范用于解决两个问题：

1. 筑基、结丹、元婴之间必须存在明确而可信的视觉差距；
2. 境界提升不能简化为“角色更亮、粒子更多、范围更大”。

力量递进的核心顺序是：

```text
身体发力
→ 御器稳定
→ 多线控制与本命法宝
→ 神识、空间与战场秩序控制
```

## 2. 称谓基线

| 境界 | 宗门内常见称谓 | 中性称谓 |
|---|---|---|
| 炼气 | 弟子、师兄、师弟 | 炼气修士 |
| 筑基 | 师叔、师伯、执事 | 筑基修士、筑基前辈 |
| 结丹 | 师祖、长老 | 结丹修士、结丹长老 |
| 元婴 | 老祖、太上长老 | 元婴修士、元婴老祖 |

具体称谓由人物关系决定，但普通筑基修士不得称为“老祖”。

## 3. 三境总览

| 维度 | 筑基修士 | 结丹修士 | 元婴老祖 |
|---|---|---|---|
| 核心力量 | 真元护体、成熟御器、神识外放 | 金丹循环、本命法宝、多线控制 | 元婴、深层神识、瞬移与神魂手段 |
| 身体动作 | 完整但短促，仍需挥剑、掐诀或转身 | 动作明显减少，以手势和意念控制为主 | 动作极少，视线、指诀或心念即可发动 |
| 常规法器 | 同时稳定控制 1～2 件，特殊招式可短暂更多 | 本命法宝为核心，可同步控制 3～6 条攻击线 | 数量不是重点，一件本命法宝即可压制结丹，多余法器表现从属控制 |
| 护体表现 | 紧贴身体，受击时显形 | 结构稳定，可形成内外两层或法宝护主 | 常态近乎不可见，接触前已通过神识或法宝化解低阶攻击 |
| 移动 | 地面身法为主，短暂御空 | 稳定飞行、空中转向与施法 | 短距瞬移、神识锁定，移动轨迹难以预判 |
| 常规影响半径 | 约 3～6 米 | 约 8～15 米 | 约 15～30 米的局部绝对压制 |
| 环境反馈 | 尘土、落叶、水波、衣摆局部响应 | 地面裂纹、植被倒伏、器物震动、局部气流改变 | 环境声衰减、空间折射、法器失稳、局部光影与感知异常 |
| 对低一境界 | 炼气难以破护体，但仍有逃生空间 | 筑基正面难敌，阵地和法器体系被压制 | 结丹也需慎重应对，低阶修士通常失去常规交战资格 |
| 画面关键词 | 稳、准、护体、双器 | 本命、阵列、领域控制、战场中心 | 安静、留白、瞬发、不可测 |

“影响半径”是常规战斗构图参考，不是硬性数值，也不代表每个技能都覆盖整个范围。

## 4. 筑基修士

### 4.1 视觉目标

> 让炼气修士感到正面难敌，但仍能理解攻击来源、寻找破绽并尝试撤离。

### 4.2 动作

- 仍有完整身体重心变化；
- 挥剑、掐诀和转身比炼气更短、更准确；
- 可以边移动边维持一件法器；
- 短暂悬空用于跨越、闪避和技能节点，不作为常态站姿；
- 受重击时仍会被迫后退或打断，但阈值明显高于炼气。

### 4.3 法器与护体

- 常规同时控制 `1～2` 件法器；
- 护体灵光紧贴身体轮廓，仅在受击或主动强化时明显；
- 法器轨迹稳定，转向半径小，回收利落；
- 不使用巨型稳定领域、大片悬浮山石和全场天象作为普通表现。

### 4.4 环境与声音

- 脚下尘土被推开；
- 附近草木、衣袖和水面出现局部压力反应；
- 法器出鞘声、真元低鸣和护体碰撞声清晰；
- 环境音乐仍保持正常，只在强招前短暂压低。

### 4.5 推荐对比画面

```text
炼气主角位于前景，法器轨迹轻微偏移；
筑基修士双脚落地或短暂离地，控制一攻一守两件法器；
护体紧贴身体，周围只有数米范围的落叶和尘土受影响；
玩家能看出难以破防，但仍能寻找符箓、阵眼或撤离路线。
```

## 5. 结丹修士

### 5.1 视觉目标

> 让筑基修士感到自己面对的不是更强的单个战士，而是一套以本命法宝为核心的完整战场体系。

### 5.2 动作

- 身体动作明显减少，通常以抬手、转腕、指诀或视线完成控制；
- 可在稳定飞行中施法和转向；
- 本命法宝可自主护主、追击和变换形态；
- 同一动作可同时驱动攻击、防御和封锁三个目的；
- 受击表现以法宝偏转、护体波动和位置调整为主，不频繁播放普通硬直。

### 5.3 法宝与阵列

- 一件本命法宝必须成为视觉中心；
- 可同步表现 `3～6` 条攻击线，但必须保持主次；
- 副剑、法轮、符阵或器影围绕本命法宝构成稳定结构；
- 法阵不应只是地面贴图，应有层级、旋转、投影与作用对象；
- 结丹法宝与筑基法器的差别体现在自主性、稳定性和控制范围，不只是尺寸。

### 5.4 环境与声音

- 影响范围扩大到一片明确战斗区域；
- 石面出现裂纹，植被倒伏，悬挂器物和水流受到持续气流影响；
- 技能结束后可保留短时灼痕、剑痕、碎石或灵气残留；
- 声音具有分层：本命法宝主音、阵列运动辅音、环境低频响应。

### 5.5 与筑基的必要差距

| 项目 | 筑基 | 结丹 |
|---|---|---|
| 主动控制 | 单次一攻一守 | 同时攻击、护主和封锁 |
| 施法依赖 | 身体动作仍重要 | 本命法宝可独立完成大部分动作 |
| 空间占有 | 局部压制 | 控制完整战斗区域 |
| 受击结果 | 护体显形并可能后退 | 法宝先行化解，真身动作很少 |
| 玩家感受 | 棘手、可撤离 | 正面体系性劣势，需特殊条件 |

### 5.6 推荐对比画面

```text
筑基角色位于近景，护体被持续压缩；
结丹修士稳定悬空或立于阵心，本命法宝处于核心位置；
三至六条攻击线封锁不同方向，地面法阵与飞行法宝共同构成空间控制；
环境出现裂纹和持续风压，但画面仍局限于洞府、山谷或庭院级战场。
```

## 6. 元婴老祖

### 6.1 视觉目标

> 让结丹修士意识到自身法宝体系仍处于对方神识与规则控制之下，同时保持局部、克制、可读的画面。

### 6.2 动作

- 肢体动作最少，常以视线、轻微指诀或静止完成发动；
- 瞬移不使用长距离高速拖影，强调位置变化和空间残留；
- 元婴离体、神魂攻击和附身类表现采用短时、明确的第二轮廓；
- 不以持续大幅挥舞和十几把飞剑证明强度；
- 真身、元婴、本命法宝之间应有清晰主从关系。

### 6.3 神识、空间与法宝

- 神识压迫可通过景深变化、声音衰减、边缘折射和低阶法器震颤表现；
- 本命法宝数量可以少于结丹，但控制精度和威慑更高；
- 结丹攻击可在接近前被偏转、停滞、瓦解或失去锁定；
- 局部空间可以出现短暂错位、残影、折线和不连续位移；
- 元婴本体出现时应简洁、短暂，避免常驻巨型神像。

### 6.4 环境与声音

- 环境首先“安静下来”，再出现力量；
- 近处水面、碎屑、火焰和悬挂物呈现异常一致的方向或停滞；
- 局部光照、雾和空间边缘发生变化，但不要求天空、山体和整个世界同时响应；
- 低频与空白比持续轰鸣更重要；
- 出手后可以迅速恢复平静，强化不可测感。

### 6.5 与结丹的必要差距

| 项目 | 结丹 | 元婴 |
|---|---|---|
| 力量中心 | 本命法宝与阵列 | 神识、元婴和本命法宝共同支配 |
| 控制方式 | 多线并行 | 更少动作、更少显性轨迹、更高控制权 |
| 空间移动 | 稳定飞行与高速位移 | 短距瞬移与位置错位 |
| 防御表现 | 法宝与护体主动拦截 | 低阶攻击在接近前失去作用 |
| 战场反馈 | 风压、裂纹、阵列 | 安静、折射、感知异常、法器失稳 |
| 对手体验 | 被封锁、被压制 | 难以判断其完整能力，常规交战目标失效 |

### 6.6 推荐对比画面

```text
结丹修士位于前景，本命法宝已展开但轨迹出现停滞或偏移；
元婴老祖站立或轻微离地，只保留一件主法宝和淡薄元婴轮廓；
空间在人物周围局部折射，水面和碎屑呈现异常静止；
画面强调“控制权已经被夺走”，而不是巨大天体、黑洞或毁灭性爆炸。
```

## 7. 特效覆盖与可读性上限

以下为 `1920 × 1080` 战斗镜头的初始验收参考：

| 境界 | 常规技能瞬时覆盖 | 章节级强招瞬时覆盖 | 必须保留 |
|---|---:|---:|---|
| 筑基 | 不超过画面约 12% | 不超过约 25% | 玩家、施法者、主攻击方向 |
| 结丹 | 不超过约 20% | 不超过约 35% | 本命法宝、阵心、撤离方向 |
| 元婴 | 不超过约 25% | 不超过约 45% | 真身轮廓、主要目标、空间边界 |

覆盖比例不是粒子发射器数量，而是高亮、不透明特效和强对比区域的综合面积。任何境界都不能以遮住整个画面作为力量证明。

## 8. 动画递进原则

```text
境界越低：准备越长、身体参与越多、受后坐力影响越明显
境界越高：准备越短、动作越少、法宝自主性越高、环境先于身体响应
```

但高境界不等于取消全部预警。面向玩家的危险技能仍必须通过法宝蓄势、环境静止、地面投影、音频变化或空间折射提供可辨识前兆。

## 9. 验收问题

每张境界对比图、每个 Boss 和每套 VFX 必须回答：

- 不看文字，能否分辨筑基、结丹和元婴？
- 差距是否来自控制方式，而不只是亮度和尺寸？
- 结丹是否明显掌控一片战场？
- 元婴是否明显夺取战场控制权，但仍局限在当前叙事场景？
- 低境界角色的失败、抵抗或逃离方式是否可读？
- 玩家轮廓、攻击方向和危险区是否始终可见？
