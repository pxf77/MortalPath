# MortalPath 美术圣经 v0.1

## 1. 核心定义

### 1.1 风格名称

> **凡尘山水·写意半写实**

英文内部标签：`Grounded Xianxia · Painterly Semi-realism`

### 1.2 核心表达

```text
可信的凡俗世界
+ 克制而明确的修仙异常
+ 境界驱动的力量层级
+ 服务即时战斗的画面可读性
+ 独立团队可持续量产的资产规格
```

美术目标不是复制任何既有影视、动画或游戏，而是建立原创的“凡人流”修仙视觉体系：普通区域首先像真实生活过的地方，仙法因此显得罕见而危险；低阶修士仍依赖身体、法器和准备，高阶修士逐步表现出对战场秩序的控制。

## 2. 五项美术支柱

### 2.1 凡尘可信

- 山川、植被、水系和道路遵循真实地貌逻辑；
- 建筑具有用途、结构、材料与生活痕迹；
- 村落、宗门、坊市、洞府和秘境必须有明确的社会功能；
- 木、石、布、金属、纸张和陶器保留磨损、潮湿、积尘与修补痕迹；
- 低阶修士与凡人的外观差异主要来自装备、姿态和器物，不靠全身发光。

### 2.2 仙法克制

- 角色平时不常驻巨大光环、发光纹路和高强度 Bloom；
- 灵力在施法、护体受击、法器启动和境界释放时出现；
- 特效应优先表现轨迹、作用范围、材质变化与环境响应；
- 强度提升首先表现为控制质量、范围、持续性和环境影响，而不是单纯变亮；
- 每个技能必须保留玩家、敌人、命中点和危险区的轮廓。

### 2.3 境界可视

玩家关闭境界文字后，仍应能从动作、法器、护体、声音和环境变化判断大致层级。

```text
炼气：身体参与明显，御器尚不稳定
筑基：御器成熟，护体稳定，局部压制
结丹：本命法宝与多线控制，掌控一片战场
元婴：动作极少，神识与法宝形成绝对威慑
```

具体量级见 [`realm-visual-hierarchy.md`](realm-visual-hierarchy.md)。

### 2.4 战斗清晰

任何战斗画面都必须优先回答：

1. 玩家在哪里、朝向哪里；
2. 敌人的攻击何时开始、覆盖哪里；
3. 玩家是否命中、是否受击；
4. 哪些物体可交互、可破坏或可躲避；
5. 当前敌人是否明显高于玩家境界。

色彩不能成为唯一信息来源。形状、节奏、地面投影、声音和动画前摇必须共同承担可读性。

### 2.5 可持续量产

- 以模块化场景、共享材质、Trim Sheet 和可复用骨骼为主；
- 主要视觉差异由轮廓、材质组合、器物和动画建立；
- 不以大量独占 4K 贴图、透明飘带和动态灯光堆叠品质；
- 先完成代表性样本，再扩展数量；
- M3 之前不追求照片级皮肤、微表情和电影级近景毛发。

## 3. 镜头与构图

### 3.1 战斗镜头基线

- 投影：正交；
- 水平朝向：以世界坐标约 `45°` 斜向观察；
- 俯角：约 `40°～45°`；
- 镜头行为：阻尼跟随，战斗中不自由旋转；
- 常规画幅：`16:9`；
- 设计基准分辨率：`1920 × 1080`；
- Combat Lab 正交尺寸可维持 `18` 左右，正式场景在 `15～20` 内按战斗密度调整。

### 3.2 屏幕占比

- 常规探索时，玩家角色高度约占画面高度的 `12%～18%`；
- 普通战斗不得因镜头过远导致武器和手势不可辨；
- Boss 战允许适度拉远，但玩家高度不低于画面高度的 `9%`；
- 建筑檐口、树冠和岩体不得长期遮住玩家躯干与攻击方向；
- 必须为地面危险区、法阵和飞剑轨迹保留负空间。

### 3.3 镜头强调

- 轻攻击不使用明显缩放；
- 技能命中以短促震动、局部停顿和声音完成反馈；
- 大境界压制可轻微拉远或降低环境声音，但不频繁切换电影镜头；
- 突破与剧情展示允许独立镜头，不改变常规战斗可读性标准。

## 4. 色彩体系

### 4.1 基础比例

```text
70% 低饱和自然环境色
20% 角色、器物和交互重点
10% 仙法、危险和剧情强调色
```

| 石灰 | `#74766F` | 山石、墙体、灰瓦 |

## 5. 角色风格

### 5.1 人体比例

- 常规角色：`7.0～7.5` 头身；
- 头部可比真实比例略大约 `5%`，保证斜俯视辨识；
- 手掌、剑、法器和关键饰件可放大 `5%～10%`；
- 不采用 Q 版大头身，也不采用远镜头下难辨识的纯八头身写实比例。

### 5.2 面部

- 东方骨相明确，眉眼与颌面具有角色差异；
- 保留结构性明暗，减少毛孔和微观皮肤噪声；
- 避免统一网红脸、塑料皮肤和过度锐利鼻梁；
- M3 的面部目标是中景可辨识，不追求电影级特写。

### 5.3 发型与发色

- 常规发色以黑、深棕、灰白为主；
- 红、银、青等特殊发色必须对应血脉、种族、功法异变或剧情身份；
- 发束形成清晰大块轮廓，减少大量细碎透明发丝；
- 战斗角色避免过长、持续遮挡身体和武器的散发。

### 5.4 服装与身份

| 身份 | 视觉原则 |
|---|---|
| 凡人武者 | 粗布、皮革、绑腿、护腕，强调劳动与实用 |
| 炼气弟子 | 与凡俗服饰连续，增加符袋、药瓶、轻便法器与宗门标识 |
| 筑基修士 | 裁剪更稳定，材质更好，护体器物和储物器具更完整 |
| 结丹修士 | 轮廓更简洁，少量高品质玉石、金属与本命法宝特征 |
| 元婴老祖 | 服饰不必最华丽，依靠姿态、留白、法宝与环境压迫表现身份 |

境界越高不等于金边越多。高境界角色应体现“动作更少、控制更稳、器物更精”。

## 6. 场景风格

### 6.1 区域设计模板

每个区域必须先确定：

```text
现实地貌参考
气候与季节
建筑时期与地域语言
当地主要材料
植被与水系
社会功能
修仙异常层
```

### 6.2 基础区域

#### 山村

- 丘陵、梯田、溪流、竹林或杂木林；
- 夯土、木构、灰瓦、泥路和石桥；
- 生活痕迹多，修仙元素极少；
- 色调偏土褐、石灰、松青。

#### 宗门

- 依山势组织山门、讲经台、药园、炼器院、任务堂和洞府；
- 建筑先满足功能，再加入阵法、灵脉和少量悬空结构；
- 云雾用于层次，不应覆盖道路和交互目标。

#### 坊市

- 商铺、仓储、客栈、防火石墙和狭窄街巷；
- 丹药、符箓、法器通过器物陈列而非霓虹招牌表现；
- 凡人、炼气与少量筑基修士共同构成社会层次。

#### 秘境

- 可明显偏离现实，但仍要有稳定的内部规律；
- 异常可以来自重力、时间、灵气、水流、植被或古阵；
- 每个秘境只确立一至两个主异常，不同时堆叠所有奇观。

### 6.3 材质气质

- 木材：高粗糙度、可见纹理与磨损，不做塑料高光；
- 石材：大块结构明确，细节随镜头层级递减；
- 布料：以褶皱大形和材质厚薄区分，不依赖复杂透明层；
- 金属：高阶器物可更精炼，但高光范围受控；
- 玉石：半透仅用于少量重点资产，避免大面积发光玉质。

## 7. 光照与天气

- 自然光占主导，阴天、晨雾、雨后和薄暮作为主要气氛；
- 室内使用烛火、灯笼、炉火和灵石灯形成局部暖色；
- 常规环境不使用无来源轮廓光；
- 高境界施法可短暂改变局部明暗、雾和阴影方向；
- 夜景必须保留人物轮廓、地面危险区和主要路径；
- Bloom 仅用于核心高亮，不作为统一滤镜。

## 8. UI 风格

> 宣纸、墨线、青玉、旧铜构成的现代简洁界面。

- 正文使用可读性优先的中文字体；
- 宋体或书法特征仅用于章节标题、境界突破和少量标识；
- 面板可使用纸张纤维、墨线、玉石和旧铜边框，但层级必须简洁；
- 朱砂只用于危险、敌意、失败和严重伤势；
- 古金只用于突破、本命法宝和章节级奖励；
- 不显示常驻精确战力数字；
- 不使用手游式红点、五彩品质光柱和多层金框；
- 生成概念图中的文字禁止直接裁切到 UI，所有字必须使用正式字体重新排版。

## 9. 叙事画面

| 场景 | 形式 |
|---|---|
| 日常探索与普通对话 | 游戏内 3D 镜头 |
| 重要人物首次登场 | 稳定构图、有限景深与局部特写 |
| 章节过场 | 2D 山水插画或淡彩定格 |
| 回忆与传闻 | 线描、淡墨、低帧动效 |
| 境界突破 | 3D 角色、环境变化、2D 墨迹与人工排版书法 |
| 世界地图 | 山水长卷式绘制 |
| 功法与法宝图鉴 | 古籍线描、结构图和器物剪影 |

## 10. 明确排除

- 照片级扫描写实作为全项目基线；
- Q 版、大头身和轻浮卡通比例；
- 通用高饱和仙侠手游美术；
- 人人常驻光环、漂浮和发光纹路；
- 全地图长期蓝紫或血红滤镜；
- 大面积金色宫殿和无功能装饰；
- 用大量半透明粒子遮盖动作问题；
- 只通过扩大特效表现境界差距；
- 直接复制既有作品的角色、宗门、法宝、服装或标志性场景。

## 11. v0.1 锁定项与待验证项

### 已锁定

- 风格名称与五项美术支柱；
- 3D 空间、固定正交斜俯视与 2.5D 构图；
- 东方半写实人物比例；
- 低饱和自然环境与局部仙法强调；
- 筑基、结丹、元婴的视觉递进原则；
- 宣纸、墨线、青玉、旧铜的 UI 方向；
- 正式文字必须人工排版。

### 需在 M1～M3 验证

- 角色在实际正交尺寸下的最优头身和武器放大比例；
- 场景雾、植被密度与战斗预警之间的平衡；
- 玉青、朱砂和五行色在不同显示器上的辨识度；
- 结丹与元婴技能的屏幕覆盖上限；
- Godot 材质和后处理能否稳定达到绘画化 PBR 目标；
- UI 正文字体与商用授权方案。
