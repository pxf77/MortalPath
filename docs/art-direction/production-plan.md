# 美术生产计划：A0～A5

## A0 · Art Direction Lock

状态：**本次完成**

产出：

- 美术圣经 v0.1；
- 筑基、结丹、元婴视觉层级；
- 资产生产规格；
- 美术验收清单；
- 初版方向参考板。

完成标准：

- 风格名称、镜头、人物比例、基础色板、材质倾向和 UI 方向明确；
- 纠正境界称谓；
- 明确筑基与结丹、结丹与元婴的控制方式差异；
- 生成图文字不作为正式资产；
- 后续样本有统一验收依据。

## A1 · Style Frames

目标：用三张无 UI、无生成文字的正式构图验证整体方向。

### Frame 1：凡尘山村

- 清晨或雨后；
- 山村、溪流、竹林、土路和生活痕迹；
- 主角仍接近凡人武者；
- 不出现高强度仙法；
- 验证山水、建筑、材质、雾和人物比例。

### Frame 2：筑基对结丹

- 山谷、废弃洞府外庭或宗门偏院；
- 筑基角色护体被压缩，本命法宝尚未形成；
- 结丹修士处于阵心，以一件本命法宝控制多条攻击线；
- 环境出现局部裂纹、倒伏和风压；
- 验证结丹对筑基的体系性压制。

### Frame 3：结丹对元婴

- 封闭洞府、古阵核心或水潭石室；
- 结丹本命法宝展开但出现停滞、偏转或失去锁定；
- 元婴老祖动作很少，使用神识、局部折射与淡薄元婴轮廓；
- 画面保持局部、克制和可读；
- 验证元婴夺取战场控制权，而非简单扩大爆炸规模。

完成标准：

- 三张图能被同一项目识别；
- 不看文字也能判断力量层级；
- 角色、场景和 VFX 都可转化为 3D 资产；
- 通过美术验收清单。

## A2 · Character Kit

目标：完成首个可量产角色套件。

产出：

- 主角正、侧、背三视图；
- `7.0～7.5` 头身比例测试；
- 凡人 / 炼气 / 筑基三阶段服装增量设计；
- 一套共享人形骨架；
- 飞剑、符袋、药瓶和护体器物挂点；
- 一名炼气敌人与一名筑基敌人的轮廓变体。

完成标准：

- 正交镜头下轮廓和武器方向清晰；
- 境界变化不依赖换一整套华丽时装；
- 角色可进入 M1 Combat Proof。

## A3 · Environment Kit

目标：建立 Realm Slice 山谷区域的第一套模块化场景资产。

产出：

- 岩石、土路、溪流、竹木和灌木；
- 石阶、残墙、木构小亭、阵眼和洞府入口；
- 一套石材 / 木材 / 地表 Trim Sheet；
- 可战斗灰盒与遮挡处理；
- 雨后、薄雾和晨光三个受控气氛预设。

完成标准：

- 支持至少三个不同战斗房间；
- 预警和角色在复杂环境中仍可读；
- 模块不依赖大量独占材质。

## A4 · Combat VFX Kit

目标：完成从炼气到结丹的最小战斗特效语言。

产出：

- 玉青御剑轨迹；
- 普攻命中、护体命中与破防反馈；
- 筑基护体和双器控制；
- 结丹本命法宝、阵列与局部环境响应；
- 五行基础形状样本；
- 境界压制音画联动测试。

完成标准：

- 不看伤害数字也能判断命中与护体；
- 筑基与结丹差距清楚；
- 峰值帧不遮挡角色和危险边界；
- 在 Godot 中达到当前 60 FPS 目标。

## A5 · UI Kit

目标：建立首个可用而非概念性的 UI 组件库。

产出：

- 生命、灵力、技能与状态 HUD；
- 神识威胁等级；
- 对话框、物品卡和功法卡；
- 宣纸、墨线、青玉和旧铜基础组件；
- 章节标题与境界突破排版样本；
- 字体与授权清单。

完成标准：

- 所有文字由正式字体渲染；
- 1080p 下可读；
- 不出现精确战力常驻展示；
- 组件能够在 M2 Realm Slice 中复用。

## 与游戏里程碑的关系

| 美术阶段 | 游戏里程碑 | 依赖关系 |
|---|---|---|
| A0 | M0 / M1 前置 | 先锁定方向，防止玩法样本风格漂移 |
| A1 | M1 并行 | Style Frame 反向验证镜头与可读性 |
| A2 + A3 + A4 | M1 → M2 | 将战斗原型替换为代表性资产 |
| A5 | M2 | 支撑神识、资源、任务与突破信息 |
| A1～A5 通过 | M3 | 才进入正式垂直切片整合 |
