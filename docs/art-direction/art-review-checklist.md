# 美术资产验收清单

## 1. 使用方式

每个角色、场景、动画、VFX 或 UI 资产进入主分支前，应在 PR 中附上：

- 资产用途与所属里程碑；
- Godot 引擎内截图或短视频；
- 正交战斗镜头下的实际尺寸；
- 性能影响和已知限制；
- 本清单的通过情况。

概念图本身不能替代引擎内验收。

## 2. 通用风格

- [ ] 符合“凡尘山水·写意半写实”，没有滑向高饱和通用仙侠手游风格；
- [ ] 现实材质、结构和生活逻辑先成立，再加入修仙异常；
- [ ] 颜色与材质处于整体色板内，特殊色有叙事或玩法用途；
- [ ] 没有常驻巨大光环、无来源轮廓光和过量 Bloom；
- [ ] 不直接复制既有作品的角色、服装、法宝、宗门或标志性构图；
- [ ] 生成图仅作为参考，正式文字、数值和图标已经人工重做。

## 3. 角色

- [ ] 在常规正交镜头下，头部、肩部、手部和武器轮廓清楚；
- [ ] 服装体现身份和使用功能，不依赖金边数量区分境界；
- [ ] 发型和衣摆不会长期遮挡武器、朝向和受击点；
- [ ] 材质能区分布、皮革、金属、木与玉，不呈塑料感；
- [ ] 骨骼、挂点和碰撞体符合生产规格；
- [ ] 动画姿态与角色境界一致；
- [ ] 模型与贴图预算合理，超预算部分可在固定镜头下看见收益。

## 4. 场景

- [ ] 道路、建筑、水系和植被符合区域地貌与社会功能；
- [ ] 模块尺度统一，门、台阶、栏杆和角色比例可信；
- [ ] 战斗场地保留移动、闪避和技能释放空间；
- [ ] 树冠、屋檐、岩体和前景不会持续遮挡玩家；
- [ ] 可交互物、危险物和装饰物有明确视觉层级；
- [ ] 雾、雨、烟尘和植被密度不影响敌人预警；
- [ ] 简化碰撞不会产生不可见卡点；
- [ ] 场景在灰度截图下仍具有前、中、后景层次。

## 5. 动画

- [ ] 前摇、有效段和后摇清楚；
- [ ] 攻击方向与实际 Hitbox 一致；
- [ ] 取消窗口和位移没有视觉欺骗；
- [ ] 低境界动作更依赖身体，高境界动作更经济但仍保留预警；
- [ ] 受击、格挡、护体和死亡反馈能区分；
- [ ] 动画循环无明显滑步、脚底漂移和武器穿模；
- [ ] 在 60 FPS 与不同帧率下时序表现稳定。

## 6. VFX

- [ ] 玩家、敌人、命中点和危险区在特效期间仍可见；
- [ ] 五行通过颜色、形状和运动共同区分；
- [ ] 预警早于伤害，边界和方向可读；
- [ ] 特效覆盖符合境界层级上限；
- [ ] 筑基、结丹、元婴的差距来自控制方式和环境响应，不只是亮度；
- [ ] 透明粒子、动态灯和后处理数量受控；
- [ ] 命中、音效、伤害事件和动画时序一致；
- [ ] 残留效果不会掩盖下一次攻击预警。

## 7. 境界专项

### 筑基

- [ ] 以成熟御器、稳定护体和局部压制为主；
- [ ] 常规控制 1～2 件法器；
- [ ] 环境影响局限于尘土、落叶、水波和局部气流；
- [ ] 不被误读为结丹或元婴级别的战场支配。

### 结丹

- [ ] 本命法宝是视觉中心；
- [ ] 可同时攻击、护主和封锁，明显高于筑基的单线控制；
- [ ] 影响一片完整战斗区域，并留下局部环境痕迹；
- [ ] 筑基角色在画面中体现护体被压缩、法器被限制或路线被封锁。

### 元婴

- [ ] 动作更少，神识、空间和法宝控制权更强；
- [ ] 不依赖巨大黑洞、天体或全屏爆炸证明强度；
- [ ] 结丹法宝在接近前出现停滞、偏转或失去锁定；
- [ ] 环境以安静、折射、感知异常和局部规则变化表现压迫；
- [ ] 画面仍保留真身、主要目标和作用边界。

## 8. UI 与文字

- [ ] 正文在 1080p 下达到最低字号和对比度；
- [ ] 书法字体没有承担长段正文；
- [ ] 关键图标在 32 px 与 48 px 下可辨识；
- [ ] 没有生成图文字、乱码、错别字和错误境界称谓；
- [ ] “筑基修士 / 结丹修士或长老 / 元婴老祖”等称谓符合关系语境；
- [ ] UI 不常驻显示精确战力数字；
- [ ] 素材与字体授权状态明确。

## 9. 技术与性能

- [ ] 资源路径、命名和导入设置符合目录规范；
- [ ] 贴图尺寸、压缩格式和材质数量合理；
- [ ] 透明材质、动态灯、粒子和骨骼数量没有异常增长；
- [ ] 目标场景在 1080p 下满足当前性能预算；
- [ ] 资产移除后不会留下失效引用；
- [ ] PR 不包含无关源文件、缓存、临时渲染和超大重复文件。

## 10. 终审截图

每个代表性资产至少提交以下截图：

1. 正常 1080p 战斗镜头；
2. 50% 缩放截图，用于检查大轮廓；
3. 灰度截图，用于检查明暗层级；
4. 特效峰值帧；
5. 无特效基础材质帧；
6. 境界对比资产需提供低一境界角色同框截图。
