# 境界与即时战斗规则

## 境界阶梯

| 大境界 | 小阶段 | 战斗质变 | 世界地位 |
|---|---|---|---|
| 凡俗 | 锻体、通脉、先天 | 武器、暗器、轻功、陷阱 | 普通人与江湖武者 |
| 炼气 | 一至九层 | 灵力、低阶法术、符箓、简单御器 | 散修与外门弟子 |
| 筑基 | 初期、中期、后期、圆满 | 真元护体、神识外放、短暂御空、多法器 | 内门精英与宗门执事 |
| 结丹 | 初期、中期、后期、圆满 | 本命法宝、持续飞行、剑阵、大范围神通 | 宗门长老与一方强者 |
| 元婴 | 初期、中期、后期、圆满 | 元婴离体、瞬移、神魂攻击、领域雏形 | 宗门老祖与区域威慑 |
| 化神 | 初期、中期、后期、圆满 | 调动天地灵气、法则雏形、区域级神通 | 人界顶点 |

首作玩家成长只覆盖至结丹初期。元婴与化神作为世界背景、高压剧情和不可常规战胜目标存在。

## 威胁指数

系统内部使用威胁指数维护世界力量秩序，但不向玩家显示精确数字。

| 境界初期 | 基础威胁指数 |
|---|---:|
| 凡俗 | 1 |
| 炼气 | 8 |
| 筑基 | 64 |
| 结丹 | 512 |
| 元婴 | 4096 |
| 化神 | 32768 |

每个大境界基础值相差 8 倍。小阶段系数：

- 初期：`×1.00`
- 中期：`×1.25`
- 后期：`×1.60`
- 圆满：`×2.00`
- 炼气一至九层在 `×1.00` 至 `×2.00` 之间线性增长。

威胁指数是生命、防御、灵力质量、恢复、感知、控制抗性、法器规模和移动能力的综合概念。基础生命、攻击和防御不直接按 8 倍膨胀，当前骨架使用威胁指数平方根进行基础属性缩放，再通过境界穿透形成实战压制。

## 境界穿透

```text
最终伤害
= 基础攻击结果
× 境界穿透
```

| 攻击者相对防守者 | 境界穿透 |
|---|---:|
| 低三个及以上大境界 | 2% |
| 低两个大境界 | 8% |
| 低一个大境界 | 35% |
| 同一大境界 | 100% |
| 高一个大境界 | 140% |
| 高两个大境界 | 180% |
| 高三个及以上大境界 | 220% |

后续还应加入：

- 低境界对高境界护体的削减效率；
- 控制、硬直和打断效率；
- 神识发现与隐匿；
- 灵压对低境界法器稳定性的影响；
- 法器品阶、功法克制和伤势；
- 阵法、符宝等特殊越阶条件。

这些压制应通过世界规则表现，不通过输入延迟、随机丢失指令或强制削弱操作手感实现。

## 交战预期

| 差距 | 预期 |
|---|---|
| 同一小境界 | 操作和构筑决定胜负 |
| 相差一个小境界 | 低境界可正常取胜 |
| 相差两个小境界 | 需要克制或消耗品 |
| 相差三个小境界 | 精英/Boss 强度 |
| 相差一个大境界 | 正面基本不可胜，依赖准备或撤离 |
| 相差两个大境界 | 不进入正常击杀流程 |

## 神识显示

不直接显示精确战力。玩家通过神识获得模糊判断：

- 压倒性优势；
- 可敌；
- 棘手；
- 凶险；
- 九死一生；
- 深不可测。

高境界目标可以隐匿气息，使判断进一步模糊。

## 突破质变基线

### 炼气 → 筑基

- 战斗：真元护体、多法器控制；
- 探索：神识扫描、短暂御空；
- 社会：进入内门、参与高阶任务与拍卖。

### 筑基 → 结丹

- 战斗：本命法宝、持续飞行、范围法阵；
- 探索：跨越危险地形、进入高灵压区域；
- 社会：开辟洞府、收徒、参与宗门决策。

### 结丹以上

首作仅做叙事与系统接口，不量产完整可玩内容。
