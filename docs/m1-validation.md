## 本批实现

1. 普攻三段有 85 / 110 / 135 ms 前摇，剑诀有 160 ms 前摇；伤害在接触时结算。
2. 240 ms 动作输入缓冲在局部停顿和闪避期间继续接收输入；过期输入不延迟误触。
3. 闪避能取消未命中的前摇，已支付的剑诀灵力及冷却不退还。
4. 第三段实际命中才回复 9 灵力，空挥不再回灵。
5. WASD 相对屏幕移动，攻击仍跟随角色朝向，不是鼠标指针瞄准。
6. 地面提示与实际判定共用扇形范围和角度；前摇更淡，接触阶段更清晰。
7. 普通命中局部闪白、受伤暖红、护体命中蓝色、破阵琥珀碎片、敌人死亡消散。
8. 局部命中停顿上限 65 ms；相机偏移独立衰减，不写 `Engine.time_scale`，不累积位置漂移。
9. 击退不影响固定阵眼，炼气不能推动筑基；筑基的常驻护体可见。
10. 胜利和失败清理飞行物、停用战斗输入，防止结算后继续掉血。
11. 初始十类程序合成声已在 2026-09-02 替换为 20 个 CC0 采样成品（14 个战斗成品、6 个预备成品），最多八声部，同类多目标命中限流；尚待人工声音设计审核。详见 [`audio-integration.md`](audio-integration.md)。

`F6` 切换减弱动态（关闭震屏和命中停顿），`M` 切换音效；设置仅作用于当前一轮。

## 复现

```bash
GODOT_BIN=/Applications/Godot_mono.app/Contents/MacOS/Godot bash scripts/validate-demo.sh

# 真实图形窗口：默认、减弱动态、静音，三轮正常输入
godot --path . --max-fps 60 --script res://tests/demo_input_runner.gd -- \
  --capture --output=res://build/m1-evidence/graphical

# 引擎帧录制，保留音频；先创建输出目录
mkdir -p build/m1-evidence/recorded
godot --path . --fixed-fps 60 --write-movie build/m1-evidence/recorded/input.avi \
  --script res://tests/demo_input_runner.gd -- \
  --capture --output=res://build/m1-evidence/recorded
```

`--capture` 在 headless 下明确失败，不会等待不存在的渲染信号。

覆盖既有规则与阶段测试；首批为 71 项 headless / 72 项图形检查，音效接入后扩展为 160 / 161 项，涉及反馈、前摇、输入、回灵、技能、闪避、护体、结算、重开、采样音频、静音及释放事件时机。

版本迁移后使用 9 项严格日志门禁检查，包括 ANSI 颜色错误、脚本错误和资源泄漏；无旧版错误豁免。完整验证脚本使用 `--import` 等待资源导入完成；迁移时隔离旧缓存并重新导入。

当前唯一验收基线为 **Godot 4.7.2 stable**。先前 4.3 / 4.7 的测试只保留为历史记录；4.3 dummy 网格清理诊断的旧豁免已删除，停止日常旧版回归。策略见 [`godot-version-policy.md`](godot-version-policy.md)。

正常输入驱动不传送、不修改气血、不强制无敌、不调用强制击杀、不直接发出胜利信号；要求每轮撤离时筑基仍然存活。JSON 记录技能次数、三段完成次数、命中、落空、受伤总量、结算和模拟时长。图形证据保存在 `build/m1-evidence/`，不提交为游戏资源。

旧 `demo_visual_capture.gd` 是带无敌和跳阶段的展示脚本，不能作为实际通关证据。新输入驱动与其分离。

本地交付证据：

- `build/m1-evidence/recorded/normal-input.mp4`：约 40 秒、1280×720、60 FPS 的引擎录制，包含两轮有声和一轮静音；这是录像帧率，不是完整性能验收结论。
- `build/m1-evidence/recorded/input-runs.json`：录制驱动三轮全部胜利，筑基存活。
- `build/m1-evidence/godot43-graphical/input-runs.json`：Godot 4.3 真实时间图形回归三轮全部胜利。
- `build/m1-evidence/validation/`：当前引擎最近一次本地回归日志。
