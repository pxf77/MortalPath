# 游戏定位

## 一句话定位

一款固定斜俯视 2.5D 修仙动作 RPG。玩家从凡俗或炼气阶段起步，在境界森严、资源稀缺且强者真实存在的世界中，通过功法修炼、法器运用、战前准备、秘境探索与谨慎战斗，逐步成长至结丹。

## 设计支柱

### 1. 境界决定力量规则

大境界不是名称和属性条。突破应改变玩家能够执行的动作、可进入的区域、能感知的信息，以及在修仙社会中的身份。

### 2. 同境界看操作，大境界看积累和准备

- 同一小境界：操作、功法和装备决定胜负。
- 相差一至两个小境界：允许通过操作、克制和消耗品取胜。
- 相差一个大境界：正面对抗基本不可胜，必须依赖伤势、阵法、情报、特殊法器或逃生目标。
- 相差两个大境界：不进入常规击杀流程。

### 3. 逃生也是有效胜利

不是所有出现的敌人都必须被玩家杀死。夺物、拖延、破阵、掩护和撤离都应成为完整任务目标。

### 4. 突破带来质变

每次大境界突破必须至少改变一类战斗能力、一类探索能力和一类社会权限。

### 5. 凡尘可信，仙法才显异常

世界首先由可信的山川、建筑、材料和生活秩序构成。仙法平时克制，施放时通过轨迹、作用范围、环境反应和境界控制权形成强调。筑基、结丹与元婴的差距来自能力和战场规则，不只是粒子数量。

## 产品形态

| 项目 | 决策 |
|---|---|
| 类型 | 单机即时战斗修仙 ARPG |
| 视角 | 固定斜俯视、正交相机 |
| 世界 | 区域式地图，不做首作无缝开放世界 |
| 主角 | 单主角持久成长 |
| 战斗 | 移动、身法、功法、法器、消耗品、遁逃 |
| 成长 | 修为积累 → 瓶颈 → 准备 → 突破 → 能力质变 |
| 美术方向 | 凡尘山水·写意半写实 |
| 美术技术 | 3D 空间与角色、绘画化 PBR、固定镜头 2.5D 构图 |
| 首作境界 | 凡俗/炼气起步，结丹初期收束 |

## 核心循环

```text
收集情报
  ↓
判断目标境界、功法与弱点
  ↓
准备丹药、符箓、法器或阵盘
  ↓
进入野外、洞府或秘境
  ↓
战斗、潜行、绕行或逃跑
  ↓
取得材料、功法与法器
  ↓
返回安全区域
  ↓
炼制、参悟与闭关
  ↓
准备并完成境界突破
  ↓
进入更高层次的区域与社会关系
```

## 首作明确不做

- 无缝开放世界；
- 联机；
- 多主角即时切换；
- 自由旋转的近身动作镜头；
- 全局等级缩放；
- 装备随机词条海；
- 炼丹、炼器、阵法、灵兽、宗门经营全部同时展开；
- 玩家仅靠无伤操作耗死任意高境界敌人；
- 元婴及以上成为首作日常刷怪对象；
- 照片级扫描写实、Q 版或通用高饱和仙侠手游作为整体美术基线。

## 原创边界

项目可以参考传统凡人流修仙叙事中的成长节奏、资源竞争和境界秩序，但不复制任何现有作品的具体人物、剧情、宗门、功法、法宝名称、服装、场景或标志性桥段。
