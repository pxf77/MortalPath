# 初版游戏 Demo v0.1

## 名称

**青岚谷脱身**

## 验证目标

这不是完整关卡，也不是美术垂直切片。它用于验证以下设计能否在同一段可玩流程中成立：

1. 固定斜俯视即时战斗是否清楚；
2. 三段普攻、主动剑诀、护体和闪避是否形成基础操作循环；
3. 近战与远程敌人的前摇是否可读；
4. 灵力消耗、恢复和技能冷却是否要求玩家作出选择；
5. 炼气同境界敌人可以通过操作击败；
6. 筑基敌人能够形成明确的大境界压制；
7. 面对高境界敌人时，“破阵并逃生”能够成为完整胜利目标。

## 流程

### 阶段一：谷口交战

玩家以炼气六层进入青岚谷，需要击退：

- 炼气五层近战散修；
- 炼气六层御器散修；
- 炼气七层远程符修。

该阶段验证同一大境界内的移动、连击、技能、护体和远程预警。

### 阶段二：锁灵阵

首波敌人被击退后，筑基初期守阵修士出现，并启动三处锁灵阵眼。玩家攻击筑基修士时，会同时受到：

- 大境界穿透差；
- 更高基础属性；
- 稳定护体带来的额外减伤；
- 近战和远程术法交替压制。

玩家的正确目标是破坏三处炼气层级阵眼，而不是正面磨死筑基修士。

### 阶段三：撤离

三处阵眼全部破坏后，南侧遁光阵恢复。玩家进入遁光阵即完成 Demo。

## 玩家能力

| 能力 | 规则 |
|---|---|
| 三段御剑 | 0.85 / 1.00 / 1.35 倍伤害，第三段可命中多个目标并回复灵力 |
| 青锋剑诀 | 消耗 30 灵力，远距离窄角度贯穿多个目标 |
| 护体灵光 | 消耗 25 灵力，短时间降低所受伤害 |
| 身法闪避 | 短距离高速位移并获得短暂无敌 |
| 灵力恢复 | 战斗中持续恢复，要求在输出与防御之间分配 |

## 当前非目标

- 正式人物模型、动作捕捉与完整动画树；
- 最终材质、正式 VFX、配乐和音效；
- 剧情对话、任务系统、存档和道具系统；
- 筑基突破玩法；
- 完整关卡导航和大型场景；
- 装备、功法树、炼丹、炼器和经济系统。

上述内容应在核心战斗验证通过后逐步接入，不应反向掩盖战斗手感问题。

## 验收方式

机器验证：

```text
Godot 工程可导入
主场景可 headless 启动
境界、连击和灵力规则测试通过
Demo 可从 intro → combat → escape 流转
三处阵眼破坏后遁光阵开启
```

人工试玩重点：

```text
攻击方向是否清楚
三段连击是否容易衔接
远程术法是否有可反应前摇
灵力是否构成真实约束
筑基压制是否明显但不让操作失效
玩家是否自然理解需要破阵撤离
```
