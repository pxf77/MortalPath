# 路线图

## A0 · Art Direction Lock

状态：**已建立 v0.1 基线**

目标：在制作正式角色、场景和特效前，锁定可供 M1～M3 使用的初版美术方向。

当前已提供：

- “凡尘山水·写意半写实”美术圣经；
- 固定正交斜俯视的镜头与构图基线；
- 角色、场景、材质、光照、VFX 与 UI 方向；
- 筑基、结丹、元婴的视觉层级；
- 资产预算、目录、生产流程与验收清单；
- 初版参考板和基础色板。

下一步：制作无字正式 Style Frame、首个角色套件、Realm Slice 场景套件和战斗 VFX 套件。

详见 [`art-direction/production-plan.md`](art-direction/production-plan.md)。

## M0 · Combat Lab

目标：证明固定斜俯视即时战斗与境界压制可以在同一最小场景内成立。

当前骨架已提供：

- 玩家移动、普攻、闪避；
- 同大境界敌人；
- 高一大境界敌人；
- 威胁指数与境界穿透；
- 调试突破；
- HUD 与神识威胁判断；
- headless 规则测试。

完成标准：

- 输入无明显丢失；
- 攻击方向和距离可判断；
- 玩家能够击败同境界敌人；
- 低一大境界时明显难以正面对抗；
- 突破后战斗关系发生可感知变化。

## M1 · Combat Proof

增加：

- 三段御剑普攻；
- 一个主动剑诀；
- 一个防御或护体技能；
- 一个远程敌人；
- 一个带护体的筑基敌人；
- 灵力资源；
- 命中停顿、受击反馈、音效和基础 VFX；
- 动作数据与取消窗口；
- 通过 A1 Style Frame 的角色轮廓、基础材质和特效样本。

完成标准：

- 无正式剧情时，外部测试者仍愿意连续战斗 5 分钟；
- 玩家能读懂敌人预警；
- 不能只靠连续按普攻解决全部敌人；
- 身法、灵力和距离管理均有实际价值；
- 美术样本符合 `docs/art-direction/art-review-checklist.md`；
- 特效峰值帧仍能看清玩家、敌人和危险区。

## M2 · Realm Slice

主题：炼气四层至筑基初期的一段完整成长切片。

内容：

1. 坊市收集情报；
2. 准备丹药、符箓与遁符；
3. 进入山谷；
4. 击败同境界妖兽；
5. 对抗炼气后期邪修；
6. 遭遇筑基修士；
7. 发现正面攻击无法有效破防；
8. 破坏阵眼并撤离；
9. 返回安全区域，准备筑基；
10. 完成突破并解锁神识与真元护体。

完成标准：

- 战斗、准备、逃生与突破形成完整闭环；
- 大境界差距通过玩法和视听表现而非说明文字被玩家理解；
- 筑基后返回旧区域能明显感知成长；
- 山谷环境套件、筑基护体、御剑和最小 UI 可稳定复用。

## M3 · Vertical Slice

制作 20～30 分钟接近最终品质的内容：

- 一个宗门小场景；
- 一个坊市；
- 一个野外区域；
- 一段主任务；
- 三种普通敌人；
- 一个精英敌人；
- 一个章节 Boss；
- 一次完整突破；
- 基础存档；
- 键鼠与手柄；
- 正式角色、场景、动画、音效和 VFX 的代表性样本；
- 筑基与结丹力量差距的章节级展示；
- 正式字体渲染的 HUD、对话、物品和功法基础界面。

此阶段通过后，才进入大规模内容生产。

## 首作后续里程碑

- `M4-first-playable`：从开场到结丹结局全流程可运行；
- `M5-alpha`：主要系统完成，内容可统计；
- `M6-beta`：内容封版，集中修复、性能和兼容性；
- `M7-release-candidate`：发行候选版本；
- `M8-release`：正式发布与热修复。
