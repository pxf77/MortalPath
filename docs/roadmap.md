# 路线图

## A0 · Art Direction Lock

状态：**已建立 v0.1 基线，并迁移至独立美术仓库**

当前已提供：

- “凡尘山水·写意半写实”美术圣经；
- 固定正交斜俯视的镜头与构图基线；
- 角色、场景、材质、光照、VFX 与 UI 方向；
- 筑基、结丹、元婴的视觉层级；
- 资产预算、生产流程与验收清单；
- 独立 Blender → glTF → Godot → Art Pack 生产流水线。

下一步：在 `MortalPath-Art` 制作无字正式 Style Frame、首个角色套件、Realm Slice 场景套件和战斗 VFX 套件。

详见 [`MortalPath-Art / production-plan.md`](https://github.com/pxf77/MortalPath-Art/blob/main/docs/art-direction/production-plan.md)。

## M0 · Combat Lab

状态：**完成**

已验证：

- 固定斜俯视 3D 战斗空间；
- 玩家移动、攻击与闪避；
- 同大境界敌人与高一大境界敌人；
- 威胁指数、属性缩放和境界穿透；
- HUD、神识威胁判断和 headless 规则测试。

## M1 · Combat Proof

状态：**初版 Demo v0.1 已实现，等待人工手感验收**

当前 Demo「青岚谷脱身」已经提供：

- 三段御剑普攻和输入缓冲；
- 主动青锋剑诀；
- 护体灵光与身法闪避；
- 气血、灵力、消耗、恢复和冷却；
- 近战、远程与筑基守阵三种敌人行为；
- 攻击前摇、范围提示和远程术法飞行物；
- 三名炼气敌人的同境界战斗；
- 筑基初期敌人的属性、穿透和护体压制；
- 三处锁灵阵眼与遁光阵撤离目标；
- 开场、胜利、失败与重开流程；
- Demo 阶段流转 headless 测试。

详见 [`demo-v0.1.md`](demo-v0.1.md)。

M1 剩余验收：

- 本地图形窗口连续试玩并调整输入窗口、移动速度和敌人前摇；
- 加入最小命中停顿、屏幕震动和正式音效；
- 从 `MortalPath-Art` 接入通过 A1 审查的角色轮廓、基础材质和 VFX 样本；
- 通过外部玩家五分钟战斗测试；
- 确认不能只靠连续普攻解决所有目标。

完成标准：

- 输入无明显丢失，三段攻击可稳定衔接；
- 玩家能够读懂近战与远程预警；
- 身法、灵力和距离管理均有实际价值；
- 玩家能够理解筑基修士不属于当前正常击杀目标；
- 特效峰值帧仍能看清玩家、敌人和危险区；
- 美术样本符合 [`MortalPath-Art / art-review-checklist.md`](https://github.com/pxf77/MortalPath-Art/blob/main/docs/art-direction/art-review-checklist.md)。

## M2 · Realm Slice

主题：炼气四层至筑基初期的一段完整成长切片。

计划内容：

1. 坊市收集情报；
2. 准备丹药、符箓与遁符；
3. 进入山谷；
4. 击败同境界妖兽；
5. 对抗炼气后期邪修；
6. 遭遇筑基修士；
7. 发现正面攻击无法有效破防；
8. 破坏阵眼并撤离；
9. 返回安全区域，准备筑基；
10. 完成突破并解锁神识与真元护体。

M1 Demo 已提前验证第 4～8 项的最小战斗结构；M2 需要补齐情报、准备、返回安全区和突破闭环。

完成标准：

- 战斗、准备、逃生与突破形成完整闭环；
- 大境界差距通过玩法和视听表现而非说明文字被玩家理解；
- 筑基后返回旧区域能明显感知成长；
- 山谷环境套件、筑基护体、御剑和最小 UI 可稳定复用。

## M3 · Vertical Slice

制作 20～30 分钟接近最终品质的内容：

- 一个宗门小场景；
- 一个坊市；
- 一个野外区域；
- 一段主任务；
- 三种普通敌人；
- 一个精英敌人；
- 一个章节 Boss；
- 一次完整突破；
- 基础存档；
- 键鼠与手柄；
- 正式角色、场景、动画、音效和 VFX 的代表性样本；
- 筑基与结丹力量差距的章节级展示；
- 正式字体渲染的 HUD、对话、物品和功法基础界面。

此阶段通过后，才进入大规模内容生产。
